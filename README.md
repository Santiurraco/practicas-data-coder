El proyecto RetailPro muestra el detalle de ventas que realiza una empresa de insumos tecnológicos en diferentes regiones del país, segmentada por categorías de productos, regiones y precios.
En este repositorio venimos trabajando con una serie de ejercicios y prácticas a partir del curso de Data Analytics de CoderHouse, utilizando el repositorio github para subir las entregas y el motor SQL Server con su management studio para aplicar los scripts y consultas.
En este ejercicio sobre los comandos SELECT y AS, lo que destacamos son las razones técnicas por las cuales no conviene utilizar la consulta SELECT* ya que nos trae toda la información de las tablas,  principalmente generado desperdicio de recursos de red y memoria y la ruptura de código ante cambios en la estructura de la tabla.
A su vez, el comando AS es muy importante como alias para modificar y adecuar el nombre de las columnas y datos para que sea entendido de forma directa y sencilla por las personas no técnicas.
